# Test plans of the Playwright Test Agents

Markdown plans written by the `playwright-test-planner` agent (`.claude/agents/`), one file per feature
(`translations.md`, ...). A plan is a draft: what is agreed goes into [TEST-PLAN.md](../TEST-PLAN.md), and tests are
written (or rewritten from the generator's draft) with the `writing-localess-e2e-tests` skill.
